<h1>Projet informatique de POO : la belote</h1>

<h3> But du jeu </h3>

Ce jeu suit les règles classique de la belote. Le but est donc de gagner.

<h2>Comment jouer ? </h2>

- Lancez le jeu depuis le terminal en collant la commande appropriée dans votre terminal à la racine du projet :

       python3 main.py
       
       python main.py
       
- Choisissez ensuite en combien de point se joue la partie.

- **Pour jouer :**
    * **Pour prendre ou passer au premier tour :** tappez "o" pour prendre ou "n" pour passer.
    * **Pour prendre ou passer au second tour :** tappez le nom de la couleur que vous souhaitez pour prendre (les termes acceptés sont écrit ci-dessous) ou "n" pour passer. 
    
          
          Pour prendre à Pique : "p", "pique" ou "Pique".

          Pour prendre à Cœur : "co", "coeur", "Coeur", "cœur" ou "Cœur".

          Pour prendre à Trèfle : "t", "trefle", "Trefle", "trèfle" ou "Trèfle".
          
          Pour prendre à Carreau : "ca",  "carreau" ou "Carreau".



    * **Pour jouer une carte :** tappez l'indice écrit à côté de la carte souaithez (les cartes grisées ne peuvent pas être jouées).


 - Dès qu'une équipe atteint le score entré lors de la seconde étape, la partie s'arrête.
